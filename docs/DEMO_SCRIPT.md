# Local demo recording script and elevator pitch

Launch the workbench on CPU before recording:

```bash
make demo
# opens http://127.0.0.1:7860
```

## Five-sentence elevator pitch

Ask a coding model how long a Python task will take and it answers on a human developer's clock, predicting seven minutes or two hours for code it writes and tests in eight seconds. Across 1,465 executable Python tasks on `CohereLabs/tiny-aya-global` (3.35B), we measured a 55x overestimation gap and found that giving the base model its tokens-per-second speed card still left a 24x typical error. Using `CuratorKIT`, `AlignTune`, and `AuditKIT`, we trained a rank-16 LoRA adapter (`M1-S0`) on measured agent trajectories and found that the tuned model predicts its own token and attempt workload well (`0.268` log10 error) while failing at single-pass verbal division (`0.272` log10 error). Feeding `M1-S0`'s predicted tokens and attempts into the exact timing formula (`M1-Struct`, zero retraining) cuts error on an unseen class-level task family (`CLASS`) to `0.269` (`1.86x`, `58.1%` within 2x), cuts 1.5 tok/s slow-hardware error 3.17x to `0.155`, and raises live desktop CPU within-2x accuracy (`llama.cpp` `Q4_K_M` at 20 tok/s) from `3%` to `63%`. Paired with split-conformal bounds (`M1-Struct+CP`), these estimates tie `DeepSeek-V4-Pro` on unseen-family shortest-job-first queue scheduling (`1.18x` oracle), cut timeout false aborts 10.5x (`13.9%` to `1.3%`), and save `26.4%` in 15-second edge-to-datacenter SLA routing at `$16` vs `~$1,700` per million batched estimates.
